# employee-attrition-prediction
 Predictive Analytics for Employee Attrition

Overview

Employee turnover is one of the highest hidden costs for modern enterprises. This project focuses on People Analytics, utilizing statistical modeling and predictive machine learning to identify the key drivers of employee attrition. By analyzing workplace factors, the goal is to forecast flight risk and provide actionable, data-driven retention strategies for HR leadership.

Project Deliverables & Workflow

Exploratory Data Analysis (EDA): Cleaned and processed HR datasets to identify underlying trends in tenure, department structures, and job satisfaction.

Predictive Modeling: Engineered a Logistic Regression classifier to predict the likelihood of an employee leaving the company.

Statistical Interpretation: Extracted feature importance to determine which specific workplace factors (e.g., compensation, commute, overtime) had the highest mathematical impact on turnover.

Data Visualization: Built visual dashboards to translate complex statistical outputs into clear business insights.

Technologies Used:

python, pandas, numpy, sklearn, scipy, statsmodels, dmba, matplotlib
